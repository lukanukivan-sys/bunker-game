# Hotfix 1.2.3a — коди входу й відновлення

- Код кімнати лишається 6-символьним.
- Персональний код відновлення лишається 10-символьним.
- Основне поле входу більше не обрізає персональний код після шостого символу.
- Якщо в основне поле вставлено 10 символів, інтерфейс відкриває форму відновлення, переносить код у правильне поле й просить окремий код кімнати.
- Біля кожного поля явно показано потрібну довжину.
- Сервер повертає окремі повідомлення для неправильної довжини коду кімнати й персонального коду.
