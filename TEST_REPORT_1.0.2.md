# Звіт перевірки «Сховище» 1.0.2

Перевірено:

- синтаксис серверних, браузерних і контентних JavaScript-файлів;
- валідність усіх семи сетингів;
- об’єднання «Стать і гендер» та «Сім’я та діти»;
- відсутність старих окремих демографічних карток у приватному стані;
- конкретний опис «Інтерсекс • Небінарна особа»;
- узгодження чайлдфрі з батьківським і репродуктивним статусом;
- пологи за вагітності, що існувала до старту партії;
- плановану народжуваність у стабільній сумісній громаді;
- пояснення причин нульової або позитивної народжуваності;
- згортання повністю розкритих карток вибулих гравців;
- баланс ресурсів, здоров’я, ролей, здібностей та експедицій;
- профілі, кампанії, набори контенту, статистику й відновлення після перезапуску;
- повний локальний HTTP-цикл партії.

Виконані команди:

```text
node validate_content.js
node test_final_simulation.js
node test_demography_102.js
node test_ui_logic_102.js
node test_balance_v1.js
node test_platform_v1.js
node test_api_v1.js
```
