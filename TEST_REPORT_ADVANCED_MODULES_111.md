# Звіт перевірки етапу 6

Перевірено модульний розширений режим у конфігураціях:

- без додаткових модулів;
- лише експедиції й ремонт;
- лише медицина;
- лише приховані ролі й цілі;
- обмін предметами + гра після вигнання;
- експедиції + медицина;
- стандартна конфігурація експедиції + ролі;
- запит із чотирма модулями, який сервер обмежує першими двома.

Також перевірено:

- динамічну послідовність фаз;
- серверне блокування вимкнених дій;
- сумісність здібностей і прихованих ролей;
- медичний модуль без експедицій;
- приватність ролей і цілей;
- створення кімнати й зміну налаштувань у лобі;
- усі попередні автоматизовані тести;
- валідність клієнтського й серверного JavaScript;
- відсутність повторюваних HTML-ID.
