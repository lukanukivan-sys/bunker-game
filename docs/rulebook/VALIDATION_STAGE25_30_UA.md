# Етапи 25–30 — синхронізація та перевірка

## Що виконано

- Додано матрицю відповідності «правило → сервер → інтерфейс → тест».
- Автоматичний релізний аудит перевіряє версії, runtime bundle, provisional-реєстр, редакційні заборони, доступність, звук і верстку.
- Внутрішні скролбари прибрано з двосторінкового режиму.
- Висоту книги збільшено, а поля сторінок зменшено без втрати структури.
- Додано автоматичні рівні щільності `normal`, `compact`, `dense`, `tight`.
- Для великого шрифту збережено доступний односторінковий режим прокручування без видимого повзунка.
- Додано регресійний тест релізної валідації.

## Що свідомо не оголошено завершеним

Вісім механічних тем лишаються `provisional`. Їхній текст уже придатний для тестового довідника, але остаточний статус `canonical` буде надано лише після завершення відповідних P0-виправлень механік.

## Критерії візуальної перевірки

- У двосторінковому режимі сторінки не мають внутрішніх повзунків.
- Footer книги не рухається разом зі сторінкою.
- Короткі сторінки тримають номер унизу.
- Довгі сторінки автоматично ущільнюються, не обрізаючи основний зміст.
- При збільшенні тексту до порогу доступності книга переходить у односторінковий scroll-режим.
