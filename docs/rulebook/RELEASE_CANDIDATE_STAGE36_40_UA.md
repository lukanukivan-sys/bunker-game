# Етапи 36–40 — релізний кандидат і супровід

## Реалізовано

- окремий release gate для RC і фінального випуску;
- детермінований release-candidate manifest;
- 10 сценаріїв приймального тестування;
- локальна opt-in діагностика без мережевої передачі;
- експорт і очищення тестового звіту з налаштувань читання;
- фінальний checklist;
- CI guard, що вимагає синхронізації механіки, тестів, довідника й журналу змін;
- PR-template із обов’язковим checklist правил.

## Чесний статус

Автоматична частина довідника готова як release candidate. Фінальний випуск свідомо заблокований, доки:

1. не закрито 8 provisional P0-тем;
2. не проведено реальне приймальне тестування з людьми;
3. `human-acceptance.json` не має статусу `passed`.

Ці блокери не маскуються автоматичними тестами.
