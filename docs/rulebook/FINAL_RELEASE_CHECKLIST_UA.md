# Фінальний релізний checklist довідника

## Автоматичні умови

- [ ] `npm run verify` успішний на Node.js 20 і 22.
- [ ] Docker smoke успішний.
- [ ] `npm run release:rulebook:rc` успішний.
- [ ] Runtime JSON і offline fallback мають однаковий SHA-256 digest.
- [ ] Усі внутрішні посилання та контекстні кнопки валідні.
- [ ] У книзі немає приватних токенів, зовнішнього HTML чи звуків перегортання.

## Механічні умови

- [ ] У `unstable-rules.json` немає відкритих P0-тем.
- [ ] Усі provisional-сторінки повторно звірені з кодом, UI та тестами.
- [ ] Фінальна формула, ресурси, медицина, голосування, детектив і зовнішній табір канонічні.

## Людське приймання

- [ ] `human-acceptance.json` має статус `passed`.
- [ ] Пройдено щонайменше 3 реальні тестові сеанси.
- [ ] Медіанний час пошуку правила — до 20 секунд.
- [ ] Немає відкритих блокувальних findings.

## Випуск

- [ ] Оновлено версію довідника й журнал змін.
- [ ] Сформовано release-candidate report.
- [ ] Виконано `npm run release:rulebook:final`.
- [ ] У PR використано checklist синхронізації правил.
