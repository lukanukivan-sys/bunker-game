# Довідкові матеріали

<a id="glossary-a-m"></a>
## Термінологія: А–М

**Автоматизація** — рівень самостійного переходу фаз системою.

**Ведучий** — учасник із правом створювати кімнату й керувати переходами.

**Відкрита характеристика** — частина досьє, внесена до загального протоколу.

**Груповий результат** — спільний висновок про стан громади.

**Криза** — формалізована проблема з визначеними варіантами рішення.

**Місткість** — гранична кількість персонажів у цільовій групі.

Канонічні назви й дозволені синоніми зберігаються у `terminology.json`. Пошук враховує обидва варіанти, але текст правил використовує основну назву.

<a id="glossary-n-z"></a>
## Термінологія: Н–Я

**Наслідки** — фаза, у якій сервер застосовує вже прийняті рішення.

**Особиста мета** — індивідуальна умова персонажа.

**Публічний стан** — безпечна частина кімнати, доступна клієнту з урахуванням ролі.

**Recovery** — контрольоване відновлення втраченого сеансу.

**Санкція** — формальний наслідок рішення ради.

**Seed** — значення, що робить генерацію відтворюваною.

**Фаза** — відрізок циклу з власним набором дозволених дій.

**Хід** — поточне завдання конкретного учасника.

<a id="faq-first-game"></a>
## FAQ: перша партія

**Де моя дія?** На вкладці «Хід» або в картці поточної фази.

**Чи можна змінити розкриття?** Після підтвердження — ні, якщо окрема здібність не каже інакше.

**Чи можна змінити голос?** До підрахунку — лише якщо інтерфейс залишає таку можливість.

**Чому я не бачу seed?** Під час активної партії він навмисно прихований.

**Чому кнопка сіра?** Дія недоступна у цій фазі, вже виконана або потребує іншої ролі.

**Чи можна грати після відключення?** Поверніться через персональний код або recovery-процедуру.

<a id="faq-disputes"></a>
## FAQ: суперечки

Спершу відкрийте контекстне правило конкретної дії. Потім перевірте поточний режим, активні модулі й статус сторінки. Якщо сторінка позначена «Уточнюється», орієнтуйтеся на фактичні дозволені дії інтерфейсу й зафіксуйте крайовий випадок для аудиту.

Не створюйте усне правило, яке змінює серверний стан. Для якісного звіту достатньо версії гри, коду кімнати без секретів, назви фази, послідовності дій та тексту помилки.

<a id="phase-reference"></a>
## Коротка таблиця фаз

- **Лобі** — приєднання, готовність, перевірка конфігурації.
- **Розкриття** — публікація характеристик.
- **Обговорення / планування** — координація без негайного ефекту.
- **Подія / криза** — вибір реакції на проблему.
- **Операції** — практичні дії, ремонт, експедиції.
- **Голосування / звинувачення** — формальне колективне рішення.
- **Кінець раунду** — підсумок і підготовка наступного циклу.
- **Фінал** — звичайні раундові дії більше не приймаються.

<a id="action-reference"></a>
## Коротка таблиця дій

Кожна дія має виконавця, ціль, умови доступу, обов’язковість і момент застосування. Перед натисканням перевірте назву цілі та наслідок. Після підтвердження дочекайтеся відповіді сервера.

Типові дії: готовність, старт, розкриття, голос події, завершення події, голосування за санкцію, перехід фази, операція, обмін, лікування, recovery-запит і одноразове отримання нового сеансу.

Повторне надсилання не повинно створювати подвійний ефект. Якщо клієнт не впевнений у результаті, він має перечитати стан, а не сліпо повторювати запис.

<a id="rule-changes"></a>
## Зміни правил

Гравецький журнал змін містить лише те, що впливає на рішення під час партії: зміну голосування, нового режимного кроку, інший критерій фіналу або уточнення доступної дії.

Технічні зміни — CI, Docker, безпечне збереження, внутрішній формат токенів — залишаються в загальному `CHANGELOG.md`, якщо вони не змінюють поведінку гравця.

Оновлена сторінка може тимчасово мати позначку «Оновлено». Версія довідника показується окремо від версії продукту, щоб було видно, чи синхронізовано текст із релізом.

<a id="accessibility"></a>
## Доступність

Довідник підтримує клавіатуру, видимий focus, закриття через `Esc`, повернення фокуса до кнопки відкриття, оголошення сторінок екранним читачем і режим без анімації.

У налаштуваннях читання можна змінити розмір тексту, міжрядковий інтервал, контраст, підказки й тип перегортання. За великих масштабів книга автоматично переходить до однієї сторінки з прокручуванням.

Перегортання сторінок завжди беззвучне. Необов’язкові звуки відкриття й закриття книги вимкнені за замовчуванням і не передають важливої інформації.
