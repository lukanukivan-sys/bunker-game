# Видання і версія

<a id="edition-version"></a>
## Поточне видання

- Продукт: `1.2.11`
- Маніфест: `rulebook-manifest-v1`
- Runtime schema: `rulebook-runtime-v1`
- Карта книги: `rulebook-book-map-v1`
- Версія довідника: `0.8.0-rc.1`
- Мова: `uk-UA`

Runtime bundle збирається детерміновано з файлів `docs/rulebook`. SHA-256 digest дозволяє перевірити редакцію, а локальний fallback відкриває ту саму перевірену версію, якщо окремий JSON-запит недоступний.

<a id="canonical-update"></a>
## Правило оновлення

Механічний PR вважається повним лише після синхронізації п’яти шарів: коду, тестів, інтерфейсу, відповідної сторінки довідника та журналу змін правил.

Сторінка зі статусом `provisional` не публікується як остаточна редакція без повторної звірки. При зміні ID сторінки потрібно оновити контекстні переходи, закладки, пошуковий індекс і тест цілісності внутрішніх посилань.
