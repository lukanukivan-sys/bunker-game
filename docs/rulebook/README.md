# Канонічна основа інтерактивного довідника

Ця папка є канонічним джерелом тексту для інтегрованого довідника-книги. Runtime-збірка, стабільне беззвучне перегортання, пошук, фільтри, закладки, offline fallback і контекстні переходи реалізовані у `public/rulebook`.

## Що реалізовано в етапах 1–5

1. Визначено аудиторії, частини книги й рівні інформації.
2. Створено канонічне сховище розділів із машинозчитуваними метаданими.
3. Зафіксовано редакційну політику й термінологію.
4. Нестабільні P0-правила винесено до окремого реєстру.
5. Побудовано повну карту 44 фізичних сторінок і 22 розворотів.

## Основні файли

- `manifest.json` — версія, частини, розділи, аудиторії й режими;
- `content/*.md` — канонічний текст із JSON front matter;
- `book-map.json` — порядок сторінок, шаблони, статуси й розвороти;
- `terminology.json` — канонічні терміни й синоніми для пошуку;
- `unstable-rules.json` — теми, які не можна називати остаточними;
- `source-inventory.json` — пріоритет джерел;
- `editorial-policy.json` — правила мови й структури;
- `../../scripts/rulebook_validate.js` — автоматична перевірка цілісності.

## Статуси

- `canonical` — текст уже можна використовувати як правило поточної версії;
- `provisional` — сторінка зверстана в карті, але потребує P0-звірки;
- `reference` — допоміжний матеріал, FAQ або покажчик;
- `technical` — версії, схеми й процес підтримки.

## Команди

```text
npm run audit:rulebook
npm run verify
```

Аудит перевіряє унікальність розділів і сторінок, безперервну нумерацію, наявність anchor-посилань, реєстрацію всіх provisional-сторінок, термінологію та заборонені формулювання.

## Що додано в етапах 6–8

6. Зафіксовано responsive UX: двосторінковий desktop, одиночні tablet/mobile, клавіатура, свайпи, focus і scroll fallback.
7. Створено машинозчитувану книжкову дизайн-систему та CSS-токени.
8. Реалізовано детерміновану runtime-збірку, loader, модель сторінок/розворотів і чисту responsive-логіку.

Додаткові файли:

- `ux-config.json` і `UX_SPEC_UA.md`;
- `design-tokens.json` і `DESIGN_SYSTEM_UA.md`;
- `TECHNICAL_ARCHITECTURE_UA.md`;
- `../../public/rulebook/*`;
- `../../scripts/rulebook_build_runtime.js`;
- `../../scripts/rulebook_architecture_validate.js`.

Команди етапу:

```text
npm run build:rulebook
npm run audit:rulebook:architecture
```

## Що додано в етапах 9–15

- оболонка книги на початковому екрані;
- desktop-розвороти й мобільна одиночна сторінка;
- клавіатура, свайпи та reduced motion;
- беззвучне перегортання та необов’язкові звуки відкриття/закриття;
- зміст, пошук, закладки та історія.

## Що додано в етапах 16–19

- виправлено показ дзеркальної лицьової сторони після середини перегортання;
- додано контекстні переходи з налаштувань голосування, відновлення, лобі, поточної фази, особової справи й результатів;
- додано фільтри за аудиторією та режимом без зміни фізичної нумерації;
- додано інтерактивні приклади циклу раунду, голосування та відновлення сеансу;
- спеціальні типи сторінок отримали окремі візуальні маркери й композиційні правила.

## Що додано в етапах 20–30

- усі 44 сторінки заповнено повним текстом і локальними схемами;
- додано налаштування читання, доступність, автоматичне вміщення та безповзунковий desktop-режим;
- додано матрицю синхронізації правил із кодом, UI й тестами;
- виконано редакційний, функціональний, візуальний, звуковий та accessibility-аудити.

## Що додано в етапах 31–35

- версіонування правил і вбудований журнал змін;
- локальний offline fallback із перевіркою SHA-256 digest;
- same-origin loader, контроль схеми та захист від path traversal;
- безпечний renderer, який екранує довільний HTML;
- стабільні знімки сторінок під час 3D-перегортання без тимчасової підміни розвороту;
- діаграми інтегровано як легкі паперові схеми без окремих важких панелей;
- звук перегортання повністю вилучено; звуки відкриття/закриття вимкнені за замовчуванням.

## Поточний стан — 0.8.0-rc.1

Книга інтегрована в початковий екран. У двосторінковому режимі внутрішні повзунки прибрано; сторінки автоматично ущільнюються до доступної висоти. Великі розміри тексту переходять у доступний односторінковий режим прокручування. Остаточна канонізація восьми механічних тем очікує завершення відповідних P0-виправлень.

## Що додано в етапах 36–40

- release gate з окремими режимами `rc` і `final`;
- 10 сценаріїв приймального тестування з ціллю знайти правило до 20 секунд;
- opt-in локальна діагностика, яка не надсилає дані мережею;
- експорт і очищення тестового звіту в налаштуваннях читання;
- фінальний checklist і чесний machine-readable статус людського приймання;
- CI guard та PR-template для синхронізації механіки, тестів, правил і журналу змін.

Команди:

```text
npm run release:rulebook:rc
npm run release:rulebook:final
npm run audit:rulebook:sync
```

`release:rulebook:final` навмисно завершується помилкою, доки відкриті provisional P0-теми або не проведено реальні приймальні сеанси.
