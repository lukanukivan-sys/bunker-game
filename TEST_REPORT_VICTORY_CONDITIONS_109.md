# Звіт перевірки — етап 4, умови перемоги

Перевірено:

- публічні правила перемоги доступні до старту партії;
- під час партії кожен гравець отримує власну приватну спеціальну умову;
- класичний режим не створює фальшивої прихованої ролі;
- кооперативний режим використовує особисту мету як третій рівень;
- фракційний і розширений режими використовують приховану роль;
- детектив використовує роль у справі;
- у фіналі є груповий результат, персональні результати всіх гравців, особисті цілі та рольові результати;
- персоналізований фінальний блок складається з трьох карток;
- старі текстові особисті цілі залишаються сумісними;
- HTML-ID унікальні;
- серверний та клієнтський JavaScript проходять синтаксичну перевірку;
- усі попередні автоматизовані тести проходять;
- новий тест `test_victory_conditions_109.js` проходить для класичного, кооперативного, фракційного, розширеного та детективного варіантів.
