# Звіт перевірки етапу 17

Перевірено:

- створення персонального 10-символьного коду для хоста й кожного нового гравця;
- відсутність чужих кодів у публічному стані кімнати;
- пряме відновлення за кодом після початку партії або в лобі;
- ротацію токена та негайне блокування старого сеансу;
- запит повернення без коду за ім’ям із підтвердженням чинного хоста;
- ручне передавання прав хоста підключеному гравцеві;
- автоматичну заміну хоста після тайм-ауту;
- повторну генерацію персонального коду та блокування старого;
- сумісність усіх попередніх тестів і збережень.

Результат: етап 17 пройшов перевірку.
