# Звіт перевірки 1.2.8 — аналізатор авторського контенту

## Окремий тест етапу

Файл: `test_content_pack_analyzer_128.js`.

Перевірено:

- неправильний рівень абсурдності створює помилку;
- записи «Лікар» і «Лікар!» визначаються як семантичний дублікат;
- подія з однозначно найкращим рішенням отримує попередження;
- експедиція без тегів отримує попередження;
- надмірна нагорода експедиції визначається;
- тестова генерація створює 10, 25 і 50 карток відповідно до запиту;
- аналізатор повертає попередній перегляд і список відомих тегів;
- збалансований набір не має структурних помилок;
- API аналізатора вимагає авторизацію;
- авторизований API повертає повний звіт;
- працездатний набір після аналізу зберігається через звичайний API;
- у кабінеті присутні панель аналізу, шаблони та посилання на інструкцію.

## Захист автора

- Попередження не змінюють чернетку.
- Набір не видаляється та не скорочується автоматично.
- Евристичні поради можна проігнорувати.
- Серверна валідація збереження залишається окремим обов’язковим рівнем захисту.

## Сумісність

Перевірено сумісність із:

- авторськими наборами схеми 1;
- імпортом та експортом JSON;
- базовими подіями й експедиціями;
- розширенням сетингів етапу 23;
- рівнями `normal`, `odd`, `absurd`;
- Render-запуском і постійним сховищем даних.

- Контент усіх семи сетингів пройшов валідацію.
- JavaScript усіх серверних, клієнтських і тестових файлів синтаксично валідний.
- Основний інтерфейс містить 374 унікальні ID; кабінет — 49 унікальних ID.
- Великий тест на 2970 записів і 100 тестових карток завершився приблизно за 52 мс у поточному середовищі.
