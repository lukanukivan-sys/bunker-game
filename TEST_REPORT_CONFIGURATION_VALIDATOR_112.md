# Звіт перевірки етапу 7

Перевіряються:

- мінімальна кількість гравців;
- місткість у режимах із відбором;
- достатність раундів для класичного відбору;
- частка картки, яку можна відкрити;
- надто швидке повне розкриття;
- мінімальна тривалість детективного розслідування;
- відкриті голоси за прихованих ролей;
- випадкове вирішення нічиєї;
- інформаційне навантаження великих груп;
- прогноз тривалості;
- рекомендації щодо раундів і розкриттів;
- блокування старту лише за критичних помилок.
