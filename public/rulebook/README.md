# Runtime-модулі довідника

Ця папка містить інтегрований книжковий інтерфейс довідника.

- `rulebook-config.js` — константи схем і подій;
- `rulebook-loader.js` — same-origin завантаження runtime bundle, перевірка схеми та offline fallback;
- `rulebook-model.js` — індекси сторінок, розворотів і anchor-переходів;
- `page-layout.js` — responsive-модель розвороту та руху;
- `rulebook-renderer.js` — безпечне виділення anchor-секцій, Markdown-renderer і контроль локальних SVG;
- `rulebook-search.js` — локальний індекс, синоніми й ранжування результатів;
- `rulebook-library.js` — закладки та дедуплікована історія читання;
- `rulebook-audio.js` — необов’язкові локальні звуки відкриття/закриття, mute і гучність; перегортання завжди беззвучне;
- `rulebook-feedback.js` — opt-in локальний тестовий звіт без мережевої передачі;
- `page-turn.js` — чиста модель переходу й тривалості анімації;
- `rulebook-shell.js` — відкриття, закриття, DOM-render, бічні панелі, focus, keyboard і swipe;
- `rulebook.css` — оболонка, сторінки, бічні панелі, responsive-режими та плавне перегортання;
- `assets/*.wav` — локальні звуки відкриття та закриття обкладинки;
- `rulebook-tokens.css` — книжкові дизайн-токени;
- `data/rulebook-data.json` — згенерований runtime bundle;
- `data/rulebook-fallback.js` — вбудований offline fallback із тим самим digest.

Кнопка відкриття розташована в hero-зоні початкового екрана перед формами створення та приєднання. Під час відкриття довідник не виконує API-запитів кімнати й не змінює ігровий стан.

## Інтерактивність і доставка

Верхня панель книги надає зміст, повнотекстовий пошук, закладку поточної сторінки, бібліотеку закладок/історії, налаштування читання та звуків обкладинки. Дані залишаються локальними, а пошук не виконує зовнішніх запитів. Повне 3D-перегортання триває 680 мс, завжди беззвучне й використовує стабільні transient-знімки сторінок; reduced motion лишається обов’язковим fallback.

Версія `0.8.0-rc.1` додає журнал змін у самій книзі, SHA-256-звірку runtime/fallback, локальний fallback без мережі та автоматичні перевірки renderer-а, URL-політики, версій і внутрішніх посилань.


## Release candidate

Версія `0.8.0-rc.1` додає release gate, приймальні сценарії, локальну діагностику та CI guard синхронізації правил. Діагностика вимкнена за замовчуванням, не читає кімнатний стан і експортується лише за прямою дією користувача.
