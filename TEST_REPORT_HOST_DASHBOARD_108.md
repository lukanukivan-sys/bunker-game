# Звіт перевірки — етап 3, панель хоста

Перевірено:

- панель доступна лише хосту;
- звичайний гравець не отримує `hostDashboard` у стані кімнати;
- готовність розкриття рахується для кожного гравця;
- під час події відображається лише факт голосування, без вибраного варіанта;
- перехід залишається небезпечним до підрахунку події;
- санкції та стан підключення відображаються без витоку ролей;
- є попередження перед переходом із незавершеними діями;
- HTML-ID унікальні;
- серверний та клієнтський JavaScript проходять синтаксичну перевірку;
- усі попередні автоматизовані тести проходять.
