# UI6 Stage 5.1 — Journal and interaction hotfix

Виправлено регресію інтерфейсу, через яку `renderGameTabs()` звертався до відсутнього елемента `gameTabTurnStatus`. Помилка переривала повний рендер екрана, тому журнал не заповнювався, а частина кнопок не отримувала обробники подій.

## Зміни
- відновлено елемент `gameTabTurnStatus` у навігації;
- оновлення статусу зроблено null-safe;
- повний журнал подій відкритий за замовчуванням;
- додано статичний регресійний тест `test_ui6_journal_regression.js`;
- оновлено cache-busting для CSS та JS.

## Перевірка
- новий регресійний тест проходить;
- усі функціональні тести проходять; два тести з випадковим конфліктом тестового порту повторно перевірені окремо;
- аудит контенту: 9439 полів;
- аудит здібностей: 105/105.
