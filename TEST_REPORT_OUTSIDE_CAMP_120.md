# Звіт тестування 1.2.0 — зовнішній табір

## Новий сценарний тест

`test_outside_camp_120.js` перевіряє:

- автоматичне створення табору після вигнання;
- приєднання вигнаного персонажа;
- окремий публічний і приватний стан;
- одну дію зовнішнього гравця за раунд;
- створення двосторонньої угоди;
- голосування активних мешканців за угоду;
- передачу ресурсів і зростання довіри;
- укріплення табору в наступному раунді;
- накопичення хроніки;
- окремий фінальний результат;
- особистий результат вигнаного персонажа.

## Регресія

Успішно пройдені всі попередні тестові набори:

- API та відновлення після перезапуску;
- баланс семи сетингів;
- набори характеристик;
- валідатор конфігурації;
- демографічні обставини;
- детективний режим і фінал;
- фінальна симуляція;
- вкладки й панель хоста;
- медичні дилеми;
- окремі цикли режимів;
- модульний розширений режим;
- пояснення шансів;
- стратегічне розкриття;
- командні операції;
- прозорий трибунал;
- умови перемоги.

Очікувані повідомлення про заборонені повторні дії в негативних тестах не є помилками збірки.

## Статичні перевірки

- `server.js` — синтаксис коректний;
- `public/app.js` — синтаксис коректний;
- `validate_content.js` — контент валідний;
- `public/index.html` — 277 ID, усі унікальні;
- ZIP-архів перевірено після пакування.
