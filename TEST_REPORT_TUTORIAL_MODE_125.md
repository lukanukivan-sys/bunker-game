# Звіт тестування — навчальна партія 1.2.5

## Окремий наскрізний сценарій

`test_tutorial_mode_125.js` перевіряє повне проходження навчальної партії трьома гравцями:

- створення кімнати з навмисно несумісними параметрами;
- серверне застосування навчального пресету;
- мінімум у три гравці;
- фіксовані катастрофу й сховище;
- цикл першого раунду без фази санкцій;
- персональне стратегічне розкриття;
- першу навчальну кризу та журнал причин;
- перехід до другого раунду;
- другу навчальну кризу;
- відкритий трибунал із варіантом «Без санкцій»;
- протокол рішення громади;
- завершення другого раунду;
- звичайний фінал і стан `tutorial.completed`;
- наявність усіх нових елементів інтерфейсу та стилів.

## Регресійна перевірка

Успішно пройдено 30 тестових файлів, що охоплюють API, режими, детектив,
модулі, характеристики, медицину, зовнішній табір, автоматичного ведучого,
передавання хоста, мережеве навантаження, seed, трибунал, фінальну симуляцію
та навчальну партію.

Повідомлення про помилки у негативних тестах є очікуваними: вони перевіряють,
що сервер відхиляє дії в неправильній фазі, повторне лікування, неправильні
коди та заборонені варіанти голосування.

## Додаткові перевірки

- `node validate_content.js` — успішно.
- Синтаксис серверного й клієнтського JavaScript — успішно.
- Дублікати HTML `id` — відсутні.
- Render-запуск через змінну `PORT` — перевірено окремим smoke-тестом.
- Коренева адреса, `/index.html` і `/api/health` — доступні.
- ZIP-архів — перевірено через `unzip -t`.
